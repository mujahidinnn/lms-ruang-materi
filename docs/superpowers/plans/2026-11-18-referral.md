# Kode referral Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tiap murid punya kode unik dan link `/daftar?ref=KODE`; sistem mencatat siapa mengajak siapa; murid melihat jumlah teman yang bergabung; admin melihat "diajak oleh" dan "mengajak" per akun.

**Architecture:** Dua kolom di `profiles`, diisi lewat RPC security definer (kolom tidak ada di grant update, jadi murid tidak bisa menulisnya). Kode ikut dari `/daftar?ref=` lewat cookie `rm-ref` sampai callback masuk, yang memanggil `claim_referral`. Tidak ada email yang dikirim.

**Tech Stack:** Astro 7 (server) + React islands, Supabase (Postgres, pgTAP di `supabase/tests`), Vitest.

**Spec:** `docs/superpowers/specs/2026-11-18-referral-design.md`

## Global Constraints

- Tanpa hadiah atau poin; tanpa undangan email oleh murid.
- Kode: 7 karakter dari `ABCDEFGHJKLMNPQRSTUVWXYZ23456789` (tanpa I, O, 0, 1).
- Cookie `rm-ref`: httpOnly, `sameSite: "lax"`, `path: "/"`, `maxAge` 30 hari, `secure` di production.
- `claim_referral` menolak: `referred_by` sudah terisi, kode tidak ada, kode milik sendiri, akun dibuat lebih dari 1 hari lalu.
- Teks UI bahasa Indonesia. Migration dijalankan dengan `npm run db:push`; tes DB dengan `supabase test db --db-url` (lihat GUIDELINE.md) dan harus rollback.

## Review Focus

- Kode milik sendiri di link: tidak tercatat, tidak ada galat bagi murid.
- Klaim kedua dengan kode lain: `referred_by` tidak berubah.
- Akun lama (dibuat > 1 hari) membuka link ref: tidak tercatat.
- `?ref=abcd234` huruf kecil atau ada spasi: dinormalkan; `?ref=<script>` atau panjang salah: diabaikan, tidak ada cookie.
- Pengajak menghapus akunnya: yang diajak tetap ada, `referred_by` menjadi null.
