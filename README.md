# Cadangan deck materi

Salinan semua deck `.pptx` dari Supabase Storage (bucket `imports`, folder
`migrasi/`). Nama file sama dengan slug kelas.

Branch ini terpisah dari `main` (tanpa riwayat bersama), hanya untuk cadangan.

Memulihkan satu deck ke Storage: unggah `<slug>.pptx` ke `imports/migrasi/<slug>.pptx`.
Menambah deck baru: unggah ke Storage seperti biasa, lalu salin file-nya ke
branch ini dan commit.
